# 💰 AI Finance Copilot (Indian Markets)

**Premium AI-powered financial advisor and stock prediction platform tailored for the Indian NSE Market.**

---

## ✨ Key Features

- **🔴 Live Ticker (NSE)**: Real-time 1-second simulated refresh rate for top Indian stocks (RELIANCE, TCS, HDFCBANK, etc.).
- **🤖 AI Predictor**: Search for any NSE ticker and get immediate AI-driven price analysis and target predictions.
- **💬 Community Hub**: Real-time chat powered by Supabase Realtime to discuss stock movements with other traders.
- **🛡️ Portfolio Management**: Track your Indian stock holdings with automatic persistence to Supabase.
- **🎓 Learn Section**: Interactive gamified learning modules for financial literacy with progress tracking.
- **🧠 AI Advisor**: A dedicated financial assistant that understands your current portfolio and gives personalized advice.

## 🛰️ Architecture & Tech Stack

This project is built for speed, aesthetics, and reliability. 

- **Frontend**: React 19 + Vite + TypeScript
- **Backend**: Supabase (Database, Auth, Realtime)
- **AI**: Groq API (High-performance LLaMA & Mixtral models)
- **Visuals**: ECharts & Vanilla CSS Glassmorphism

For a detailed breakdown of all libraries and tools, see [TECHNOLOGIES.md](./TECHNOLOGIES.md).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- Supabase Project (URL and Anon Key)
- Groq API Key

### Installation

1. **Clone the repository**
   ```bash
   git clone <repo-url>
   cd "2026 gift"
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Environment Variables**
   Create a `.env.local` file and add:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_anon_key
   VITE_GROQ_API_KEY=your_groq_key
   ```

4. **Run Development Server**
   ```bash
   npm run dev
   ```
